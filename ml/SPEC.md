# Sift spam model — parity contract (norm_v1 · tok_v1 · feat_v1 · score_v1 · SPMH v1)

The Python reference (`ml/src/smsml/`) and the Kotlin port (`spamcore/`) must produce **identical** normalized
text, token ids and hashed features, and scores within 1e-4, for every input. Golden fixtures generated by
`s10_golden.py` enforce this. Any change to this file requires bumping the matching version string and
regenerating the bundle.

Design rule: nothing parity-critical depends on a Unicode character database except NFKC/NFD/NFC
normalization. Every character class below is an explicit code-point list. No regular expressions.

Terminology: "code point" (cp) = a Unicode scalar value. Kotlin iterates code points (`String.codePoints()`), never
UTF-16 chars. "ASCII letter" = `A–Z a–z`; "digit" = `0–9`; "alnum" = letter or digit.

## norm_v1 — `normalize(raw: String) -> Normalized`

`Normalized` fields: `clean`, `enc`, `ng` (strings), `urls` (list of `Url`), and the counters `cp_count`,
`emoji_count`, `invisible_count`, `lookalike_count`, `dropped_count`, `non_gsm7` (bool).

1. **Code points.** Decode `raw` into code points. Any surrogate code point (U+D800–DFFF, i.e. unpaired) becomes
   U+FFFD. Keep the first 2000 code points. `cp_count` = number kept.
2. **Raw stats** (on the list from step 1):
   - `non_gsm7` = any cp not in `resources/gsm7_v1.txt` (GSM 03.38 default alphabet + extension table).
   - `emoji_count` = number of cps in the EMOJI set: U+1F000–1FAFF, U+2600–27BF, U+2300–23FF, U+2B00–2BFF.
3. **Invisible characters.** Remove every cp in the INVISIBLE set:
   U+00AD, U+034F, U+061C, U+115F–1160, U+17B4–17B5, U+180B–180F, U+200B–200F, U+202A–202E, U+2060–206F, U+3164,
   U+FE00–FE0F, U+FEFF, U+FFA0, U+1BCA0–1BCA3, U+E0000–E007F, U+E0100–E01EF.
   `invisible_count` counts removed cps **except** the emoji helpers U+200D, U+FE0E, U+FE0F, U+E0020–E007F (they
   are removed but don't count, so ordinary emoji sequences don't look like obfuscation).
4. **Lookalike census** (on the step-3 list, before NFKC): for each cp ≥ U+0080, let `f` = NFKC of that single cp.
   If `f ≠ cp` and `f` is non-empty and consists only of ASCII alnum, it's a lookalike; otherwise, if the cp is a key
   of `resources/confusables_v1.tsv`, it's a lookalike. `lookalike_count` = number of lookalikes.
5. **NFKC** of the whole string.
6. **Confusables.** Replace each cp that is a key in `confusables_v1.tsv` by its ASCII value (1–2 chars). ASCII
   cps are never keys.
7. **Strip marks.** NFD; delete cps in U+0300–036F, U+1AB0–1AFF, U+1DC0–1DFF, U+20D0–20FF, U+FE20–FE2F; NFC.
8. **Punctuation map.** U+2018 U+2019 U+201A U+201B U+2032 U+02BC → `'`; U+201C U+201D U+201E U+201F U+2033 → `"`;
   U+2010 U+2011 U+2012 U+2013 U+2014 U+2015 U+2212 → `-`; U+2022 U+2043 → `*`.
9. **Restrict.** For each cp:
   - controls U+0000–001F and U+007F–009F → space (not counted);
   - EMOJI set → space (already counted in step 2);
   - U+0020–007E and the CURRENCY set {U+00A2 ¢, U+00A3 £, U+00A5 ¥, U+20AC €, U+20B9 ₹} → kept;
   - anything else → space, and `dropped_count += 1` unless the cp is U+FFFD (decoding damage, not sender content).
10. **Collapse** runs of U+0020 into one; trim both ends. Result: `clean`.
11. **URL scan** over `clean` (see below) → `urls`.
12. `enc` = `clean` where each URL token's core is replaced by the URL's `host` (leading/trailing stripped punctuation
    is kept around it). `enc` is the encoder input.
13. `ng` = `enc` with ASCII `A–Z` lower-cased and every digit replaced by `0`. Used for n-grams and the near-duplicate
    memory.

### URL scanner

Split `clean` on U+0020 into tokens. For each token:
- Strip leading cps in `([{<"'` and trailing cps in `.,;:!?)]}>"'`, repeatedly. The remainder is the **core**; skip
  empty cores.
- Let `low` = ASCII-lower-cased core. A core is **schemed** if `low` starts with `http://` or `https://` (drop that
  prefix to get `rest`) or with `www.` (`rest` = `low`); otherwise `rest` = `low`. The **authority** is `rest` up to
  the first of `/ ? #`. If the authority contains `@`: for a schemed core keep only what follows the last `@` and set
  `at_sign`; for an unschemed core the token is an email address, not a URL. The **host candidate** is the
  authority up to the first `:`. It must split on `.` into ≥ 2 non-empty labels.
- The core is a URL if one of:
  1. it is schemed;
  2. **bare domain**: the host candidate has ≥ 2 labels split on `.`, every label is non-empty and only
     `[a-z0-9-]`, the last label is all letters and is listed in `resources/tlds_v1.txt`, and the first label isn't
     all digits. If the last label is also listed in `resources/tld_stoplist_v1.txt` (TLDs that are common English
     words, e.g. `so`, `me`, `it`, `how`), there must also be a `/` after the authority, or ≥ 3 labels, or a `-` or
     digit in the second-to-last label;
  3. **IPv4**: the host candidate is four dot-separated decimal labels, each 1–3 digits with value ≤ 255.
- For a URL, record:
  - `host` = host candidate without a leading `www.`;
  - `tld` = last label (empty for IPv4);
  - `domain` (registrable): the last 3 labels if the last 2 labels joined by `.` are listed in
    `resources/psl_lite_v1.txt`, else the last 2 labels (the whole host for IPv4);
  - flags: `ip_host`, `punycode` (any label starts with `xn--`), `at_sign`, `shortener` (`domain` in
    `shorteners_v1.txt`), `risky_tld` (`tld` in `risky_tlds_v1.txt`), `brand_lookalike` (see below), `official`
    (`domain` is an official domain of any `brands_v1.tsv` row).
- `brand_lookalike`: for each row `keyword<TAB>official1,official2,...[<TAB>mode]` of `brands_v1.tsv` (mode `sub`
  or `word`; default `sub` if the keyword is ≥ 5 cps, else `word`): the keyword *matches* `host` if mode is `sub`
  and it occurs as a substring of `host`, or (either mode) it equals one of the host's words (split `host` on `.`
  and `-`). If it matches and `domain` is not one of the official domains → true.

## tok_v1 — WordPiece (BERT uncased) over `enc`

1. Lower-case ASCII `A–Z`.
2. Split on spaces into words. Within each word, every ASCII punctuation cp (33–47, 58–64, 91–96, 123–126) becomes
   its own word; runs between them stay together. (CURRENCY cps are not punctuation.)
3. WordPiece each word with `vocab.txt` (line index = id): a word longer than 100 cps → `[UNK]`. Otherwise greedy
   longest-match-first from the start; continuation pieces are prefixed `##`; if any position has no match, the whole
   word becomes one `[UNK]` (id 100).
4. `ids = [101] + pieces[0:126] + [102]`; attention mask = all ones; no padding.

Contract test: identical to `BertTokenizerFast` of all-MiniLM-L6-v2 applied to `enc`, on the full corpus.

## feat_v1 — sparse hashed n-grams over `ng`, plus 27 metadata values

**Feature strings** (three families):
- CHAR: let `s = " " + ng + " "`; every substring of length 3, 4 and 5 (by cp) → `"c:" + gram`.
- WORD: tokens are maximal runs of `[a-z0-9]`; additionally each cp in CURRENCY and `$` is a one-cp token. In order:
  `"w:" + t` for each token and `"b:" + t1 + " " + t2` for each adjacent pair.
- URL: per URL `"u:" + domain`, `"h:" + host`, `"t:" + tld` (skip empty tld).

**Hashing.** Deduplicate strings within a family and process them in ascending code-point order (this fixes the
floating-point summation order). For each: `h = murmur3_x86_32(utf8(str), seed = 0x53504D31)` as
unsigned 32-bit; `index = h & 0x3FFFF` (2^18 buckets); `sign = +1 if (h >>> 31) == 0 else -1`.

**Values.** For each family separately: `v[index] += sign * idf[index]` (double); drop entries that are exactly 0;
L2-normalize (skip if empty). The feature vector is the sum of the three family vectors, as (index ascending,
float32 value). `idf` comes from the bundle (`idf[i] = ln((1 + N) / (1 + df_i)) + 1` over the training split).

**Metadata** — 27 values, exactly this order, each in [0, 1] (float32):

| # | name | definition |
|---|---|---|
| 0 | `len_log` | `min(ln(1 + cp_count) / ln(1001), 1)` |
| 1 | `url_count` | `min(n_urls, 3) / 3` |
| 2 | `url_shortener` | any URL with `shortener` |
| 3 | `url_ip_host` | any URL with `ip_host` |
| 4 | `url_risky_tld` | any URL with `risky_tld` |
| 5 | `url_punycode_or_at` | any URL with `punycode` or `at_sign` |
| 6 | `url_brand_lookalike` | any URL with `brand_lookalike` |
| 7 | `phone_number` | see below |
| 8 | `email_address` | a non-URL space token of `clean` that has ≥ 1 cp before an `@` and a `.` after it |
| 9 | `currency_amount` | in `ng`: a cp of CURRENCY or `$` immediately followed or preceded by `0` (optionally across one space), or a token `usd` / `dollars` / `bucks` immediately preceded by a token that is all `0` |
| 10 | `optout_stop` | `ng` has the word `stop` and one of the words `reply`, `text`, `txt`, `send`, `opt` (word = WORD token) |
| 11 | `otp_pattern` | a WORD token of 4–8 `0`s in `ng` (a 4–8 digit number) **and** one of the words `code`, `otp`, `passcode`, `verification`, `pin`, `0fa` ("2FA" after digit folding), or the adjacent words `one` `time` |
| 12 | `upper_ratio` | uppercase ASCII letters / max(1, ASCII letters), on `clean` |

| 14 | `excl_count` | `min(count of '!' in clean, 5) / 5` |
| 15 | `emoji_count` | `min(emoji_count, 5) / 5` |
| 16 | `invisible` | `min(invisible_count, 3) / 3` |
| 17 | `lookalike` | `min(lookalike_count, 4) / 4` |

| 19 | `non_gsm7` | `non_gsm7` |
| 20 | `url_official` | any URL with `official` (legit notices link to the brand's own domain) |
| 21 | `snd_short_code` | sender kind SHORT_CODE |
| 22 | `snd_long_code_nanp` | sender kind PHONE with a +1 (NANP) number |

`s07b_sender_prior.py` (domain priors validated on the modern dev split); on-device personalization never changes
them. Booleans are 1.0 / 0.0.

**phone_number.** Scan `clean` for maximal runs of cps in `0123456789+-.() ` (the set includes space) that start
with a digit, `+` or `(`. A run counts if it holds 10–15 digits. Trailing spaces in a run are ignored.

## score_v1

```
z = bias + Σ_i w_embed[i]·(e[i] − mu_embed[i]) + Σ_j w_meta[j]·(m[j] − mu_meta[j]) + Σ_k w_hash[idx_k]·val_k
p = 1 / (1 + exp(−z))
```
accumulated in double. `e` is the encoder's L2-normalized 384-d embedding. Fallback (no embedding):
`z_fb = fb_bias + fb_scale·Σ_k w_hash[idx_k]·val_k + Σ_j w_meta_fb[j]·(m[j] − mu_meta[j])`.

## Near-duplicate similarity

`sim(a, b)` = cosine of the two feat_v1 sparse vectors (dot product divided by both L2 norms; 0 if either is
empty). Accumulate in double.

## SPMH v1 — weights container (little-endian)

```
"SPMH"                       4 bytes magic
u16 format = 1
u16 n_blocks
n_blocks × 32-byte entries:  name[16] (ASCII, zero-padded) · u32 dtype (1=f32, 2=i32, 3=u8, 4=f64) · u32 count · u64 offset
payload                      each block at its offset, offsets 16-byte aligned, zero padding between
u32 CRC32 (IEEE 802.3)       over every preceding byte
```

Base head blocks: `bias`(f64×1), `w_embed`(f32×384), `mu_embed`(f32×384), `w_meta`(f32×27), `mu_meta`(f32×27),
`w_hash`(f32×262144), `idf`(f32×262144), `fb_bias`(f64×1), `fb_scale`(f64×1), `w_meta_fb`(f32×27).
The personalized file uses the same container with blocks `meta`(u8×n, UTF-8 JSON), `w_embed`(f32×384),
`w_meta`(f32×27), `hash_idx`(i32×k) and `hash_val`(f32×k) (the k hashed weights that differ from the base head), and
is written via temp file + atomic rename.
